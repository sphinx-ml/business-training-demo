# Train AI on a Business, using Sphinx

Download the runnable Cedar Bank example from [Releases](https://github.com/sphinx-ml/business-training-demo/releases/latest), unzip it, and follow the included README.

The example contains synthetic company records, SQLite data, ten analyst questions, and an automated comparison. It uses the published Sphinx Python SDK and the standard production training API. All company data is fictional. API keys and prior run state are not included.

Read the [walkthrough](https://docs.sphinx.ai/examples/business-training), train using your own Sphinx project API key, and generate your own evaluation results.
